# Доработка Crypto TV Terminal — спецификация для Claude Code

Этот документ описывает **5 новых функций** табло и как они реализованы поверх
существующего кода `app/src/main/assets/web/`. Изменения уже внесены в файлы этого
пакета — здесь объясняется, что и где менялось, чтобы их можно было ревьюить,
поддерживать и при необходимости переносить в нативный UI.

> Архитектура не сломана: слой данных (`config.js` → `api.js` → шина `FEED`) не
> тронут. Вся новая логика — в слое UI (`i18n.js`, `settings.js`, правки `terminal.js`,
> `index.html`, `terminal.css`). Кнопка «Назад» на пульте по-прежнему закрывает любое
> модальное окно через `MainActivity.kt` → `closeOverlay()`, потому что **все попапы
> рендерятся в тот же `#ctv-overlay`**.

## Новые / изменённые файлы

| Файл | Статус | Назначение |
|---|---|---|
| `i18n.js` | **новый** | Словарь RU/EN, `I18N.t()`, локализованные даты и `relTime`. Подключать ПОСЛЕ `api.js`, ДО `settings.js`. |
| `settings.js` | **новый** | Состояние пользователя (localStorage) + три попапа (hero / watchlist / news) + D-pad навигация. Подключать ПОСЛЕ `i18n.js`, ДО `terminal.js`. |
| `index.html` | изменён | Переключатель языка в шапке, шестерёнки на панелях, hero-бар, `data-i18n`-атрибуты, подключение `i18n.js` + `settings.js`. |
| `terminal.css` | изменён | Тумблеры, попапы настроек, адаптивная hero-сетка, таблица крупных сделок, переключатель языка, фокус-кольца D-pad. Добавления — в конце файла, помечены блоком-комментарием. |
| `terminal.js` | изменён | N-карточек hero, watchlist из настроек, фильтр новостей по источникам, окно крупных сделок (таблица+фильтры+сводка), `applyLanguage`, привязки. |
| `mock-api.js` | **новый, только превью** | Имитация шины `FEED` с фейковыми данными — чтобы прототип «жил» в браузере без сети. **В APK не нужен** (там реальный `api.js`). |
| `prototype.html` | **новый, только превью** | Копия `index.html`, где `api.js` заменён на `mock-api.js`. Для просмотра дизайна. **В APK не нужен.** |

Порядок подключения скриптов в `index.html` (важно):
```html
<script src="config.js"></script>
<script src="data.js"></script>
<script src="api.js"></script>     <!-- реальные данные -->
<script src="i18n.js"></script>    <!-- переопределяет window.relTime локализованным -->
<script src="settings.js"></script><!-- определяет window.SETTINGS, window.initSettings -->
<script src="terminal.js"></script><!-- рендер; в initTerminalUi() зовёт initSettings() -->
```

> ⚠️ **Тонкость JS:** объявления `const FOO` в обычном `<script>` НЕ становятся
> свойствами `window`. Поэтому `SETTINGS` и `I18N` явно экспортируются
> (`window.SETTINGS = SETTINGS; window.I18N = I18N;`). `terminal.js` обращается к ним
> как `window.SETTINGS`. Не убирайте эти экспорты.

## Хранилище настроек (localStorage)

Ключ `ctv.settings.v1`, форма:
```js
{
  lang: 'ru',                       // 'ru' | 'en'
  heroSymbols: ['BTC','ETH'],       // 1..6; ПЕРВЫЙ — крупная карточка (featured)
  trackedAssets: ['BTC','ETH', …],  // пул watchlist (вкл. закреплённые BTC/ETH)
  disabledNewsSources: []           // имена из CONFIG.newsSources, которые ВЫКЛЮЧЕНЫ
}
```
- `BTC` и `ETH` — закреплённые (`SETTINGS.PINNED`): всегда отслеживаются и доступны для hero.
- Максимум hero-карточек — `SETTINGS.HERO_MAX = 6`.
- Геттеры/сеттеры: `SETTINGS.heroSymbols`, `setHero(arr)`, `trackedAssets`, `setTracked(arr)`,
  `rotatingPool()`, `newsEnabled(name)`, `setDisabledNews(arr)`, `lang`, `setLang(l)`.
- Все сеттеры сразу пишут в localStorage. Санити-проверки — в `load()`.

## 1. Смена языка RU / EN (только интерфейс)

**Где:** сегментированный переключатель `#lang-switch` в правом краю шапки
(`index.html`), две кнопки `RU` / `EN`.

**Логика:** `i18n.js` хранит словарь `DICT.ru` / `DICT.en`.
- Статические строки помечены в HTML атрибутом `data-i18n="ключ"` (и `data-i18n-ph` для
  placeholder). `I18N.applyStatic()` проставляет `textContent`/`placeholder` по всему DOM.
- Динамические строки (рендерятся в JS) берутся через `T('ключ')` (alias `I18N.t`) —
  watchlist-табы, заголовки уровней hero, ликвидации, категории новостей, окно сделок и т.д.
- Даты в шапке: `I18N.months()` / `I18N.dow()` (массивы для текущего языка).
- Относительное время на карточках: `i18n.js` переопределяет `window.relTime`
  локализованной версией (RU: «5 мин», EN: «5m»).
- Числа, цены, тикеры **не переводятся** — единая финансовая нотация (en-US) на обоих языках.

**Применение:** `terminal.js → applyLanguage(lang)`:
1. `SETTINGS.setLang(lang)` → localStorage; 2. `I18N.set(lang)` → `applyStatic()`;
3. подсветка активной кнопки; 4. перерисовка динамики (часы, watchlist, hero, фандинг,
газ, ликвидации, новости, лента, F&G, альтсезон через сохранённые `lastFng`/`lastGlobal`).

Вызывается по клику языковой кнопки и один раз на старте (`initTerminalUi`) из
сохранённого языка.

**Добавить строку перевода:** добавьте ключ в оба объекта `DICT.ru`/`DICT.en` в `i18n.js`.
Для нового статического элемента — повесьте на него `data-i18n="ключ"`.

## 2. Настраиваемый центральный блок (hero) — до 6 валют, адаптивная сетка

**Управление:** шестерёнка `#hero-cfg-btn` в hero-баре → попап «Карточки в фокусе».
Тумблер на каждой валюте; ★ задаёт **крупную** (featured = первая в массиве); порядок
включения = `#2, #3…`; при 6 выбранных остальные строки гаснут (`.disabled`).
«Применить» → `SETTINGS.setHero(...)` → `CTV.applyHero()` → `renderHeroes()`.

**Рендер (`terminal.js`):**
- `heroList()` возвращает `SETTINGS.heroSymbols` (фолбэк `['BTC']`).
- `renderHeroes()` ставит `#hero-row[data-count="N"]`:
  - **N ≤ 2** — как раньше: `grid-template-columns: 1fr` (1 карта) или `1fr 1fr` (2 карты),
    обе **полные** (`heroFullHtml`: цена, 24ч/7д, area-график, поддержка/сопротивление).
  - **N ≥ 3** — класс `.has-feature`: слева **крупная** полная карта (`1.32fr`), справа
    контейнер `.hero-rest` с компактными картами (`heroCompactHtml`: иконка, тикер, цена,
    24ч/7д, мини-area-спарклайн). При rest > 3 у `.hero-rest` добавляется `.cols2`
    (две колонки) → сетка 3×2 на 6 карт.
- `onMarkets()` обновляет состояние **всех** выбранных hero-символов
  (`heroList().forEach`, `ensureHero(sym)` создаёт запись из `ASSETS`), считает уровни
  `computeLevels`, затем `refreshHeroes` (троттлинг вспышек 1 с, как в §11 ТЗ).

**CSS:** селекторы `.hero-row[data-count]`, `.hero-row.has-feature`, `.hero-rest(.cols2)`,
`.hero.compact …` — в конце `terminal.css`.

## 3. Выбор отслеживаемых активов (watchlist) — тумблеры

**Управление:** шестерёнка `#wl-cfg-btn` в шапке панели «Обзор рынка» → попап
«Отслеживаемые активы». BTC и ETH — `.locked` (значок замка «закреплено», тумблера нет).
Остальные — тумблеры вкл/выкл. «Применить» → `SETTINGS.setTracked(...)` →
`CTV.applyWatchlist()` → `applyWatchlistSettings()`.

**Логика (`terminal.js → applyWatchlistSettings`):**
```
WATCHLIST_CFG.fixedAssets  = SETTINGS.PINNED            // BTC, ETH сверху
WATCHLIST_CFG.rotatingPool = SETTINGS.rotatingPool()    // выбранные минус закреплённые
WATCHLIST_CFG.windowSize   = clamp(1..6, pool.length)
rotIndex = 0; renderWatchlist()
```
Ротация окна (существующая `rotateWatchlist`, интервал 45 с) работает поверх нового пула.

## 4. Выбор источников новостей — тумблеры по каждой ленте

**Управление:** шестерёнка `#news-cfg-btn` в шапке панели «Новости» → попап
«Источники новостей». Источники из `CONFIG.newsSources` сгруппированы по языку (EN / RU),
у каждого — тумблер. Быстрые действия (chips): **Все EN**, **Все RU**, **Снять все**.
«Применить» → `SETTINGS.setDisabledNews(...)` → `CTV.applyNews()` → `renderNews()`.

**Логика фильтрации (`terminal.js`):** источник включён, если его имени НЕТ в
`disabledNewsSources` (`SETTINGS.newsEnabled(name)`). Фильтр применяется в трёх местах:
- `onNews(n)` — новости из выключенных лент игнорируются при поступлении;
- `pickPanelNews()` — фильтр для правой панели (на случай уже накопленных в архиве);
- `renderNewsOverlayPage()` — фильтр для окна «Все новости».

> Это фильтр **отображения**. Опрос RSS в `api.js` не менялся — он по-прежнему опрашивает
> все источники по ротации; выключенные просто не показываются. Если нужно НЕ опрашивать
> выключенные (экономия трафика) — в `api.js` перед запросом проверяйте
> `SETTINGS.newsEnabled(src.name)` и пропускайте. (Опционально, не реализовано.)

## 5. Кнопка и окно «Все транзакции» (крупные сделки)

**Кнопка `#whale-all-btn`** переоформлена: иконка-график + текст + **бейдж-счётчик**
`#whale-count` (число сделок в архиве, обновляется в `updateWhaleCount()` из `renderWhale`).

**Окно (`terminal.js → openWhaleOverlay` / `whaleTableHtml`):**
- **Сводка** (3 карточки): Притоки 24ч / Выводы 24ч / Чистый поток — суммы считаются из
  `whaleArchive` парсингом строк `usd` (`parseUsd`: «$138.76M» → 138_760_000).
- **Фильтры** (chips): Все / Притоки / Выводы — состояние `txFilter`; клики ловятся
  делегированием на `#ctv-overlay-body` (в `initTerminalUi`), перерисовывают тело окна.
- **Таблица**: колонки Время · Тип (pill приток/вывод) · Актив · Количество · Сумма ·
  Направление (адрес/биржа). Шапка `position: sticky`.

Открывается той же `openOverlay()`, поэтому пульт «Назад» закрывает окно штатно.

## D-pad навигация на пульте (внутри попапов)

Существующее табло полагается на нативный фокус WebView; новые **модальные** попапы
получают собственную навигацию (`settings.js`):
- При открытом `#ctv-overlay` стрелки ←↑→↓ выбирают ближайший `.selector` элемент
  **пространственно** (`spatialPick` по центрам прямоугольников, штраф за поперечное
  смещение) и подсвечивают его классом `.focus` (см. фокус-кольца в `terminal.css`).
- `Enter`/`OK` — активирует сфокусированный элемент (`.click()`).
- Все интерактивные элементы попапов помечены классом `.selector`.

Если позже захотите единую D-pad-навигацию и по самому табло — тот же `spatialPick`
можно расширить на элементы вне оверлея (сейчас намеренно ограничен оверлеем, чтобы не
конфликтовать с нативным фокусом WebView).

## Дизайн-токены новых элементов
Используются существующие переменные из `:root` (`terminal.css`). Ключевое:
- **Тумблер `.tgl`**: off — `--inset-2` + `--ink-3` knob; on — фон `rgba(31,217,138,.22)`,
  бордер `rgba(31,217,138,.55)`, knob `--up` со свечением `--up-glow`.
- **Шестерёнка `.panel-cog`** 38×38, радиус 10, фон `--inset`; фокус/hover → `--cyan`.
- **Язык `.lang-switch`**: пилюля; активная опция — градиент `--cyan → --cyan-2`, текст `#04121a`.
- **Строка попапа `.cfg-row`**: фон `--inset`, бордер 1.5px; выбранная — `rgba(31,217,138,.4)`
  бордер + лёгкий зелёный фон; фокус — бордер `--cyan` + кольцо `--cyan-dim`.
- **Кнопка «Применить» `.cfg-apply`**: градиент cyan, как язык-актив.
- **Таблица сделок**: карточки сводки `.txov-sumcard` (фон `--inset`); pill `.txov-pill.in/.out`
  на полупрозрачном up/down; строки 70px, hairline-разделители.

Анимации — общая кривая `--ease` (`cubic-bezier(.32,.72,0,1)`), как во всём табло.

## Чек-лист после интеграции
- [ ] Язык переключается, перевод покрывает шапку/панели/попапы/окна; выбор сохраняется после перезапуска.
- [ ] Hero: 2 карты = прежний вид; 3–6 = крупная + компактные; набор и «крупная» сохраняются.
- [ ] Watchlist: BTC/ETH закреплены; выбор активов меняет список и ротацию; сохраняется.
- [ ] Новости: выключенные источники исчезают из панели и окна; сохраняется.
- [ ] «Все транзакции»: бейдж-счётчик, сводка, фильтры приток/вывод, таблица.
- [ ] Пульт «Назад» закрывает любой попап/окно; стрелки + OK работают внутри попапов.
- [ ] OTA: при выкладке поднять `webVersion` (см. README репозитория) — APK не пересобирать.

## Превью без сети
Откройте `prototype.html` в браузере: тот же UI с фейковыми данными (`mock-api.js`) —
цены «дышат», новости и сделки прилетают, все попапы и язык работают. Для устройства
используется `index.html` + `api.js` (реальные данные).
